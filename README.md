# Assignment 3: Callback-Based Utility System

## Description

This assignment focuses on understanding and implementing JavaScript callback functions to perform different operations on arrays, strings, and numbers.

## Topics Covered

1. Array processing using callbacks.
2. Squaring numbers in an array.
3. Filtering even numbers.
4. String processing using callbacks.
5. Converting strings to uppercase.
6. Counting words in a sentence.
7. Performing calculations using callbacks.
8. Arithmetic operations (Addition, Subtraction, Multiplication, and Division).
9. Finding the first matching element in an array.

## Bonus Challenge

Menu-Driven Calculator using JavaScript functions and callbacks.

### Bonus Features

- Addition
- Subtraction
- Multiplication
- Division
- Array Analysis

- `question1-9.js` – Solutions for all 9 assignment questions.
